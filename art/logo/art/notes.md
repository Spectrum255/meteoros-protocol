# 独立 logo 方案（5 变体，平面矢量）

> 目录：`art/logo/art/`
> 生成器：`art/logo/gen_logo_art.py`（Pillow；从 8× 画布 nearest 缩到 512，硬边、无渐变/发光/3D）
> 运行：`python art/logo/gen_logo_art.py`
> 产物：`logo_art_v1..v5.png`（512×512 RGBA 透明底）、`contact_sheet.png`（五档 512/128/64/32/16，深灰 `#181A1E`）、`_16px_check.png`（16×16 → 4×）。
> 与 Lead 的 `logo_v1..v4.png` 无关；未改 `tools/gen_logo.py`。

## 1. 共同规则

- 纯图形、无字母；对称或旋转对称为主，剪影优先。
- 色板：描边 `#33383D`、瓷白 `#F7F4EC`、钢 `#9AA3A8`、黄铜 `#E8B23C`、深蓝 `#00023D`、青 `#73FBFD`；六相点缀只用小圆点（白/红/黄/紫/蓝；青由主色承担）。
- 每个变体 **8 色**，无纯黑；512 画布四周至少 36 px 透明边。
- 工业语言：法兰环、螺栓、叶片、铆接槽、警示色只用小面积；粒子语言：中心青核 + 相位色点/粒子通道/光束。
- 16px 只保留「剪影 + 深色中心 + 青核」三层；叶片、螺栓、相位点在 16px 会合并，属于有意取舍。

## 2. 变体

### v1 — Hex Iris（推荐）
- 立意：六角工业法兰 + 六叶虹膜，中央青核像被收束的六相粒子；「观测/收束」比「爆炸」更符合 mod 的工厂调性。
- 剪影：平顶六边形，内部钢环 + 6 片瓷白叶片 + 深蓝圆孔 + 青核；六角中边 6 颗铜螺栓，叶片上红/黄相位点。
- 16px：六边形徽章 + 深色圆孔 + 青点，仍能读；叶片与螺栓消失，不影响身份。
- 颜色：EDGE / PORC / STEEL / BRASS / NAVY / CYAN / RED / YELLOW（8）。

### v2 — Phase Turbine
- 立意：六叶涡轮把粒子旋入中心；钢圈与铜螺栓是转子/法兰，青核是轴心。
- 剪影：圆形钢圈 + 6 片瓷白叶片 + 深蓝轮毂 + 青核；紫/蓝相位点落在两片叶片上。
- 16px：白色风车 + 青心，读作「旋转/涡轮」；比 v1 更动态，但六边形辨识度略低。
- 颜色：EDGE / PORC / STEEL / BRASS / NAVY / CYAN / PURPLE / BLUE（8）。

### v3 — Prism Splitter
- 立意：三角棱镜把一束青粒子从顶点导入，在腔体中分成多相；三角形剪影刻意避开 Lead 的立方体方案。
- 剪影：等轴测三角棱柱（正面瓷白、侧面钢灰），顶点青色光束进入圆形深蓝腔体；白/红相位点。
- 16px：三角 + 青点，像「棱镜/分束器」；侧面白带保留方向感。
- 颜色：EDGE / PORC / STEEL / BRASS / NAVY / CYAN / WHITE / RED（8）。

### v4 — Orbital Wafer
- 立意：一块圆角「相片/晶片」，对角粒子通道贯穿中央六角窗；四角铜夹是测试夹具。
- 剪影：圆角方片 + 钢内框 + 对角深蓝通道 + 中央六角窗 + 青核；黄/紫相位点在通道两端。
- 16px：方片 + 对角线 + 青心，读作「芯片/载片」；四角夹与相位点会合并。
- 颜色：EDGE / PORC / STEEL / BRASS / NAVY / CYAN / YELLOW / PURPLE（8）。

### v5 — Hex Lattice
- 立意：六角星晶格 + 内六角环，六个尖角是相位节点；最几何、最锐利的一版。
- 剪影：六角星（12 顶点）+ 钢六角环 + 深蓝六角孔 + 青核；蓝/白相位点在星尖。
- 16px：星形 + 青心，剪影最强；内环与铆钉消失，可能偏「星」而不够「机器」。
- 颜色：EDGE / PORC / STEEL / BRASS / NAVY / CYAN / BLUE / WHITE（8）。

## 3. 16×16 自检（见 `_16px_check.png`）

| 变体 | 16px 读法 | 结论 |
|---|---|---|
| v1 Hex Iris | 六角徽章 + 深孔 + 青心 | **最好**，轮廓与中心都保留 |
| v2 Phase Turbine | 白色六叶风车 + 青心 | 可读，动态感强 |
| v3 Prism Splitter | 三角 + 青点 | 可读，方向明确 |
| v4 Orbital Wafer | 方片 + 对角线 + 青心 | 可读，细节合并 |
| v5 Hex Lattice | 六角星 + 青心 | 可读，剪影最强、工业感最弱 |

- 推荐 **v1**：工业法兰/螺栓/虹膜的结构语言最完整，16px 下六边形 + 青核仍成立；v2 是更动态的备选，v5 适合做更抽象的「星标」方向。
- 色数全部 8；无纯黑；512 四边透明；16px 五个剪影互不相同（生成器逐字节断言）。
