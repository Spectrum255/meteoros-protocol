# Meteoros Protocol 美术风格规范（v0.5 · 2026-11-05）

> 范围：2D 物品图标、方块贴图、调色板与像素规范。3D 模型（Blockbench/bbmodel）由 mod-modeler 负责，本文件只约定其贴图输入。
> 权威顺序：`docs/items-and-equipment.md`、`docs/six-phase-voltix.md`、`docs/industry-basics.md` > `art/README.md` > 本文件。发现冲突以 docs 为准，并回写本节。

## 1. 视觉基调

- 一句话：**实验室搪瓷仪器被改造成工业设备**。瓷白外壳 + 钢/黄铜/深蓝/玻璃 + 黑灰描边（`#33383D` 级，不用纯黑）；**六相颜色只做状态显示**（v0.4，见 §10）。
- 比例：瓷白 55–65%，钢/黄铜/深蓝 25–35%，炭黑 10–15%；单个状态元素不超过 5%。
- 不要：黑色战术风、写实金属反射、霓虹紫大面积、照片纹理缩小、渐变/抗锯齿、表面平铺六色条/六色槽/六格灯。
- 机器单方块正面可旋转；正面必须有仪表/观察窗/进气口三者之一；每台机器最多一个状态灯/窗。
- 进气塔是唯一保留六格容量屏的方块。

- **V⁺/V⁻ 不能合并**：机器用相邻双灯或一对反向箭头；电容/电池用黄紫双色条；紫色面积可以稍大，但不与深蓝相邻（会发灰）。
- **以太白**不能平铺在瓷白上：要么珍珠光 + K 描边，要么放在深蓝玻璃衬底上。

## 3. 像素硬规则

1. **16×16 PNG，RGBA，透明背景**；特殊大件才 32×32；盔甲未来 64×32（layer1/layer2）。
2. **alpha 只有 0 或 255**，无半透明、无抗锯齿、无渐变。
3. **1px 黑灰外描边（`#33383D` 级）**包住整个剪影；不用 `K #1B1D21` 做最外圈。
4. **四周 1px 透明安全边**：所有不透明像素必须落在 `x/y ∈ 1..14`；描边也算。这样物品栏里不会贴边、放大不糊。
5. **2–3 阶明暗**：高光 `W/H` → 基色 `p/S/U` → 阴影 `q/s/Q/u`；光源统一**左上**。
6. **剪影优先**：先能读出是什么，再加细节；16×16 内不画超过 1px 宽的细节。
7. **每件一个主色**，其余为瓷白/钢/炭黑；功能色面积不超过 35%。
8. 不写文字、不画底座/投影、不用拉伸纹理、不用照片缩小。
9. **工具类物品（扳手等）默认斜 45° 摆放**：头在右上、握柄在左下，对称轴为 **`x + y = 15`**（镜像 `(x,y) ↔ (15-y, 15-x)`），整体 alpha 剪影与色块都关于该轴镜像对称；生成器用 `diag_ok()` 逐像素断言。竖放/横放仅作例外。禁止偏轴 C 头、弯柄、放大镜式结构（用户 2026-11-05 修正；早先的竖放版作废）。
10. **六色只做状态（v0.4）**：每台机器/每段管道最多一个状态灯/状态窗/小仪表；方块 2×2（材料件可 1×1），物品一个状态点或 ≤3×3 小窗，管道侧面一个窄窗 + 端面一个小点；空/停机=钢灰或深蓝，运行/选中=当前相色。禁止在表面平铺六色条、六色槽或六格灯。唯一例外是进气塔的六格容量屏。详见 §10。

## 4. 物品图标规范

- 规则：白底物品主体瓷白 + 黑灰外轮廓（`#33383D` 级）；**工具类默认斜 45° 摆放：头右上、柄左下、沿 `x+y=15` 轴对称**；竖放/横放仅作例外；武器斜 45°、枪口朝右上；装备正面或半侧面；握柄/底部用 `q/s` 压重。
- 文件：`art/sprites/<item_id>.png`、`<item_id>-alt.png`；item_id 用注册名小写：`wrench`、`canister`、`particle_nozzle`、`energy_coil`、`porcelain_shell_item`。
- 生成器：`python art/gen_sprites.py` → 10 张 PNG + `art/sprites/contact-sheet.png`（8× 最近邻 + 棋盘格）+ `art/sprites/wrench-preview.png`（扳手 8× 轴检）。生成器自带 `validate()`：尺寸 16×16、RGBA、alpha 0/255、四边透明、色数统计。
- 交付路径（由 mod-dev 接入）：
  - 贴图：`src/main/resources/assets/meteorosprotocol/textures/item/<item_id>.png`
  - 模型：`models/item/<item_id>.json` 的 `layer0` 改为 `meteorosprotocol:item/<item_id>`（当前是 `minecraft:item/iron_ingot` 等占位）。
- 现有 5 件物品的造型语义（来自 docs）：
  - `wrench`：钢制活动扳手 + 红握柄 + 黄金属箍；**斜 45° 直柄、沿 `x+y=15` 轴对称**（用户 2026-11-05 修正；竖放版作废，覆盖本行旧表述）。
  - `canister`：竖玻璃筒 + 瓷白上下盖 + 相色束带，内容物分层可见。
  - `particle_nozzle`：以太亲和合金 + 玻璃 + 钢（P0 简化铜 + 玻璃 + 铁）。
  - `energy_coil`：铜 + 金 + 红石。
  - `porcelain_shell_item`：白色混凝土 + 石英 + 玻璃（所有瓷白机身的共同材料）。

## 5. 方块贴图规范（下一批）

- 16×16 可平铺；正面/侧面/顶面分开命名：`<block_id>_front.png`、`_side.png`、`_top.png`（或按 mod 约定做 atlas）。
- 通用解剖：底部 2px 拉丝钢底座；正面 4×6 玻璃观察窗（`G` 边 + `C/B` 内 + `W` 高光）；四角钢螺丝（`S` + `K`）；瓷白面留 1–2 处磕碰露钢（`s/K`）；色块成片，不撒噪点。
- 警示条：`R`/`Y` 45° 斜条、2px 宽，**用图案重复，不拉伸**；只出现在热端、排放口、舱门边框。
- 玻璃/灯/接口要能一眼区分：灯 = 自发光 `C/Y` 块 + 1px `K`；玻璃 = `G` 框 + `B/b` 内 + `W` 高光；接口 = `B` 内腔 + `S` 环。
- 纹理键必须带命名空间：`meteorosprotocol:block/<name>`。当前 block model 里是裸名（如 `phase_separator_atlas`），会解析到 `minecraft:`，接入时必须修。
- 32×32 只给特殊大件；机器 GUI 背景 176×166（未来）。

## 7.5 已定造型（2026-11-05）

**扳手（m00355 定案：斜 45° 轴对称）**
- 用户原话：**“扳手图看上去很奇怪，正常的扳手手柄都是笔直且扳手整体轴对称的。”** 随后明确：竖放作废，按原版物品通用斜 45°。
- 定案：画布 16×16，对称轴 **`x + y = 15`**（左下 (0,15) → 右上 (15,0)）；头在右上、握柄在左下；镜像 `(x,y) ↔ (15-y, 15-x)`；主图开口扳手：U 形开口沿轴朝右上，两颊等宽，头外轮廓沿轴约 8–9px、宽约 7–8px；2px 直柄沿轴；红握柄夹轴等宽；黄金属箍在红柄与钢柄之间。备选盒式环头：环中心在轴上、孔沿轴、同轴直柄，不得读成放大镜。
- 理由：旧偏轴 C 头 + 斜柄被读成勺子/放大镜；竖放虽稳，但与“原版物品通用斜 45°”不符。
- 检查：`art/gen_sprites.py` 的 `diag_ok()` 逐像素断言 alpha 剪影关于 `x+y=15` 对称（2026-11-05 实测色块也 0 处不一致）；`art/sprites/wrench-preview.png` 是 8× 轴检图（红色虚线轴 + `45° AXIS / SYMMETRY PASS`）。
- 实现口径：主图 U 头（颈 5、颚 11、口 5×5，u×v 单位）、备选厚环（孔 3×5，u×v，沿轴）；钢头/钢柄 `S/H/s`、红握柄 `R`（近端角 `W`、远端角 `r`）、黄箍 `Y`；为满足严格轴对称，工具允许**镜像对称的 bevel 明暗**（外缘 `H`、口沿 `s`），不强制左上光源。

**其余 4 件（Lead refine 定方向，待落图；暂停，等扳手这版确认）**
- 粒子喷嘴：机器件剖面/侧视——左法兰 + 螺栓、中瓷白短筒 + 一圈细玻璃观察环、右铜喉 + 钢喇叭口，开口朝右；不要大镜头/满正面窗；备选为竖直安装变体（喇叭口朝下）。
- 能量线圈：骨架 + 3–4 圈铜绕组 + 金端帽 + 红石核心；一端黄、一端紫小端子（V+/V−）；不要大电线。
- 瓷白外壳：主图保留白板，蓝点改小号六相六点标记或瓷质铆钉；备选改叠放的两片薄板/带凹槽砖。
- 储粒罐：保留青/黄/红三色分层（不做六相六色，16×16 会糊）；顶部端盖加瓷白圈。

## 8. 工作流与交接

1. 概念/方向（docs + `art/concept-*.png`）→ 定剪影与主色。
2. 16×16 像素化：优先 `art/gen_sprites.py` 程序化绘制（可复现、可 diff）；复杂物件可手绘后用生成器校验。
3. 自检：`validate()` + contact sheet + 缩小到 1× 看剪影 + 与原版占位物品并排看辨识度。
4. 报 Lead：状态（完成/阻塞/待确认）、新增/修改文件、预览路径、验证结果、下一步。
5. Lead 批准后交 `mod-dev` 接入；美术侧不写 `src/main/resources`、不删旧图、不启动游戏。

## 9. 禁忌清单

- ❌ 抗锯齿/渐变/半透明阴影 ❌ 拉伸警示条 ❌ 贴图里写字 ❌ 超过 16px 的细节 ❌ 全黑战术风 ❌ 大面积霓虹紫 ❌ 以太纯白平铺瓷白 ❌ 深蓝当描边/阴影 ❌ **工具偏轴 C 头/弯柄/放大镜式结构**（2026-11-05 用户修正）❌ **工具竖放/横放无理由不采用**（m00355 默认斜 45°）❌ **表面平铺六色条/六色槽/六格灯**（v0.4）❌ **一台机器多个状态灯并排/多相读数贴图**（除进气塔）❌ **相色做装饰边框/大面积底色**（v0.4）❌ AI 生图直接当最终贴图 ❌ 未授权写 `src/main/resources` ❌ 删除/覆盖用户旧图。

## 10. 工业风修订（v0.4，2026-11-05，当前方向）

> 本节覆盖 §1/§4/§5/§6/§7 中与“表面平铺六色”冲突的表述；旧样张移入 `art/concepts/archive_pre_industrial/`。

### 10.1 原则
- 机器/管道/物品走正常工业/实验室设备风：瓷白外壳 + 拉丝钢 + 黄铜 + 深蓝 + 玻璃；红/黄只做热端、警示、刻度。
- 六种粒子颜色**只做状态显示**，不做装饰。每台机器/每段管道最多一个状态灯/状态窗/小仪表；空/停机=中性（钢灰 `s` 或深蓝 `B/b`），运行/选中=当前相色 + 1px `W` 高光。
- 唯一例外：进气塔保留六格容量屏（六相同时可见）。
- 六相选择/多相读数只在 GUI；模型表面不画六条色带、六格灯、六色槽。

### 10.2 状态灯尺寸与位置
- 方块：2×2（16×16 内）；材料件/小件可 1×1。位置：正面右上、仪表右侧或核心窗内；不压主剪影，留 1px `K` 边。
- 物品：一个状态点（2×2）或一个小窗（≤3×3）；不画六格。
- 管道：侧面一个窄窗（1×2 或 2×2），端面一个小点（1×1）；未连接的 core 面=分配核心状态窗。
- 状态色：当前相色；无内容=钢灰 `s/S` 或深蓝 `B`；告警可选红 `R` 小点。
- 同一台机器不要两种以上状态色同时亮；相色面积 ≤5%。

### 10.3 材料与配色
- 瓷白 `p/W/q` 55–65%；钢 `S/H/s` 15–20%；黄铜 `D/F/d` 8–12%；深蓝 `B/b` 5–10%；玻璃 `G/g` 少量；相色状态 ≤5%。
- 红/黄只做热端、警示条（1px 黄黑或红黄）、刻度；不要满面板红/黄。
- 六相色沿用 §2：Ae `W` / Th `R` / Cr `C` / Vp `Y` / Vm `V` / Aq `B`；状态点用相色，不做渐变。

### 10.4 方块清单（工业版）
- `machine_frame` 六面通用建筑块：细钢框 + 四角螺栓 + 平瓷白面，无正面/状态灯/相色；`thermal_generator` 热端红 + 仪表 + 一个状态灯；`phase_separator` 单离心腔 + 一个相色状态灯；`weather_station` 表盘 + 一个天气状态灯；`weather_tank` 液位窗 + 一个相色状态灯；`porcelain_shell` 材料板 + 一个状态点（可空）；`infinite_energy` 黄铜笼 + 一个充能状态灯；`infinite_particle_cell` B 六棱碑体块 + 一个核心状态窗 + ∞；`particle_pipe` core+arm + 一个窄状态窗。
- 16×16 草案见 `art/concepts/industrial_machines.png`；纹理在 `art/concepts/industrial/sprites/block_*.png`。

### 10.5 物品清单（工业版）
- `wrench`（沿用 45° 轴对称）、`canister`（一个相色液窗 + 黄铜箍 + 深蓝底）、`filter_cartridge`（钢筒 + 一个青色指示窗）、`particle_nozzle`（瓷白短筒 + 黄铜喉 + 钢喇叭 + 青窗）、`energy_coil`（铜绕组 + 金端帽 + 红石芯 + 一个状态点）、`porcelain_shell_item`（白板 + 四角螺丝 + 一个状态点）、`infinite_particle_canister`（一个状态灯 + ∞）、`particle_detector`（青屏 + 侧探针）。
- 见 `art/concepts/industrial_items.png`；PNG 在 `art/concepts/industrial/sprites/item_*.png`。

### 10.6 采样与禁忌
- 16×16 full-bleed（方块贴图无 1px 透明边距）；1px 黑灰边（`#33383D` 级）；无 AA/渐变；相色只出现在状态元素。
- ❌ 表面平铺六色条/六色槽/六格灯 ❌ 一台机器多个状态灯并排/多相读数贴图（除进气塔）❌ 相色做装饰边框/大面积底色 ❌ 两种以上状态色同时亮（除 GUI）。

## 10.7 侧面细节（v0.5）

方块侧面不再留纯瓷白：每台机器在左/右/后侧加 **1–2 个工业细节**，仍遵守“每台最多一个状态灯/窗、六色只做状态”。

| 方块 | 侧面细节（择一或两件） |
|---|---|
| `machine_frame` | 细钢框 + 四角螺栓，六面通用（无正面/灯） |
| `thermal_generator` | 横向散热鳍片 + 底部黄黑警示小条 |
| `phase_separator` | 细管/法兰 + 检修盖板 |
| `weather_station` | 百叶/传感器格栅 |
| `weather_tank` | 小液位窗或管道接口 |
| `porcelain_shell` | 竖向接缝 + 2 颗螺栓（保持素净） |
| `infinite_energy` | 散热格栅 + 接线端子 |
| `infinite_particle_cell` | 六边形凹板/黄铜端口环（不用六色） |
| `particle_pipe` | arm 侧壁黄铜箍 + 2 铆钉；窄状态窗保留 |

规则：细节只用瓷白/钢/黄铜/深蓝；不加六相色条；不与状态窗竞争；16×16 下每个细节至少 2×2 px；侧面纹理与正面同尺寸、同 full-bleed 采样。
