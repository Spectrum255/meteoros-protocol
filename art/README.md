## 备注

- 机器是单方块、正面可旋转；正面必须有仪表/观察窗/进气口。
- 物品图标 16×16 时，白底物品要加炭黑描边；每件只有一个主色。
- 以太元纯白不能平铺在瓷白上：用珍珠光 + 炭黑描边，或放在深蓝玻璃里。
- 流量子深蓝只做流体/玻璃/面板，不做描边和阴影。
