# 进气塔按钮图标（16×16，1×）

> 目录：`art/gui/icons/`
> 生成器：`art/gui/gen_gui_icons.py`（Pillow，确定性；`python art/gui/gen_gui_icons.py`）
> 用途：进气塔 GUI 三颗 `IconButton`（电源 / 红石 / 抽取）。最终按 **16×16 原尺寸**居中画在 20×20 原版按钮上，**不缩放**。
> 外框规则：所有剪影边界都是 `#33383D`，不用纯黑；透明底，alpha 只有 0/255。

## 1. 设计意图

### `icon_power.png` — 电源 / 启停
- 通用电源符号：12×12 圆环（2px 厚）+ 顶部 6px 开口 + 4×5 竖条，竖条与圆环之间各留 1px 透明。
- 为什么不用拨动开关：16×16 下开关的轨道 + 滑块至少要 1px 高光/阴影才能读出方向，容易被按钮灰底吃掉；电源圆环是跨语言符号，缩到 16px 仍成立。
- **单态**：关闭状态由程序侧换 tooltip，不画第二个灰态。

### `icon_redstone.png` — 红石信号
- 红石火把：8×6 红色火头（`#EB3324`）+ 2×2 黄色热芯（`#FFFD55`）+ 1px 暗红底（`#A61E13`），4×6 铜杆（`#C0692F`/`#8A451E`）。
- 两侧各一道 2px 深灰信号弧（`#33383D`），从火把中段向外张开；弧线只用 2px 宽，避免 1px 细节消失。
- 读法：先认出「火把」，再看两侧弧线 =「信号/红石控制」。

### `icon_extract.png` — 抽取
- 10×12 罐体：窄钢盖（`#9AA3A8`）+ 10px 宽肩 + 瓷白罐身（`#F7F4EC`）+ 底部 2px 青色液面（`#73FBFD`/`#2CAFBE`）。
- 罐内一个向下箭头：2px 竖杆、8px 宽箭头、2px 尖，全部 `#33383D` 描边 + `#73FBFD` 填充。箭头在罐体内部，读法是「往罐子里装」而不是通用下载图标。
- 罐体宽度 10px、高度 12px，是三个图标里主体最大的，保证 1× 下轮廓清楚。

## 2. 调色板（全部来自 style-guide）

| Hex | 用途 | 图标 |
|---|---|---|
| `#33383D` | 剪影/描边/信号弧 | 三个都用 |
| `#F7F4EC` | 罐身瓷白 | extract |
| `#9AA3A8` | 钢盖 | extract |
| `#73FBFD` | 冷光：电源竖条、抽取箭头/液面 | power, extract |
| `#2CAFBE` | 冷光暗阶（竖条右侧、液面暗阶） | power, extract |
| `#EB3324` | 红石火头 | redstone |
| `#A61E13` | 火头暗底 | redstone |
| `#FFFD55` | 火头黄芯 | redstone |
| `#C0692F` | 铜杆亮 | redstone |
| `#8A451E` | 铜杆暗 | redstone |

没有纯黑、没有调色板外颜色；`alpha` 仅 0/255。

## 3. 16×16 可读性

| 图标 | 不透明像素 | 主体 bbox | 剪影色占比 | 轮廓对比（vs `#C6C6C6`） |
|---|---|---|---|---|
| `icon_power.png` | 72 | 12×12（x2–13, y2–13） | 92% | 6.93:1 |
| `icon_redstone.png` | 92 | 12×12（x2–13, y2–13） | 65% | 6.93:1 |
| `icon_extract.png` | 112 | 10×12（x3–12, y2–13） | 59% | 6.93:1 |

- 四周留 2–3px 透明边；主体都在 12×12 内。
- 所有「贴到透明」的像素都是 `#33383D`（生成器逐像素断言），所以在原版灰按钮上不会出现「白边融进灰底」。
- 彩色特征最小 2px（圆环、竖条、信号弧、箭头杆）；1px 只用于 `#33383D` 外轮廓，没有孤立 1px 点（生成器断言每个不透明像素至少 2 个不透明 8 邻域）。
- 青色 `#73FBFD` 对灰底的亮度对比只有 1.38:1，红色 2.44:1，所以它们**只做内部填充/状态色**，轮廓始终由 6.93:1 的深灰承担；在 1× 缩略图里先看到的是轮廓，再看到颜色。
- 1× 自检结论：电源=环+竖条；红石=火把+两侧弧；抽取=罐体+罐内下箭头——三个都能在 16×16 下区分（见 `contact-sheet.png` 的 1× 对照与按钮 mock）。

## 4. 验证

`gen_gui_icons.py` 自带 `verify()`，每次运行检查：

- 16×16、RGBA、alpha ∈ {0,255}、颜色 ⊆ 上表；
- bbox 在 1..14 内，且 ≤12×12；
- 每个剪影像素都是 `#33383D`；
- 无不透明像素少于 2 个不透明 8 邻域的孤立点；
- 剪影色占比 ≥30%，不透明像素 ≥60；
- `#33383D` 对 `#C6C6C6` 的对比 ≥4.5:1。

## 5. 接入提示

- 资源路径（由 dev 复制）：`assets/meteorosprotocol/textures/gui/icons/icon_power.png` 等，对应 `meteorosprotocol:gui/icons/icon_power`。
- 在 `IconButton` 里按 **16×16 原尺寸**画在 20×20 按钮中央：偏移 `(x+2, y+2)`；不要 `blit` 放大，不要加额外边框。
- 只画一种状态；tooltip 文案（启动/停止、红石控制、抽取）由 lang 和按钮逻辑提供。
- 不要改 `art/gui/` 下现有 12 张原版风贴图；不要动 `src/**`。
